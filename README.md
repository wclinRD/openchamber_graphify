# openchamber-graphify

OpenChammer/OpenCode extension plugin that displays `graphify-out/graph.html` in the Work Status section when present.

## Features
- Shows a native status panel named **Graphify Graph**.
- Detects `graphify-out/graph.html` within the currently open project.
- If found, displays a full interactive graph generated by [Graphify](https://github.com/cogito12/graphify) using `vis-network`.
- If the file is missing, shows a helpful message and prompts to run `graphify .` first.

## Requirements
- A project that contains a `.gitignore`, has been processed with Graphify, and produces `graphify-out/graph.html`.
- OpenChammer/OpenCode extension system support for status sections and local services.

## Install / Use
Place this directory into your OpenChammer/OpenCode extensions location (e.g., via **Settings → Extensions**) or add it to your workspace as a local extension. When Graphify has generated `graphify-out/graph.html` in the project root, open the project and expand **Graphify Graph** in the Work Status section.

## Directory Structure
```
package.json           # Extension manifest and service declaration
status/                # Status section HTML and script (guest page)
  index.html
  main.js              # Loads the graph from local service and embeds it in an iframe
service/               # Host-level HTTP service that safely reads graphify-out/graph.html relative to a project dir
  main.js              # /graph endpoint returning { html } with authorization
```

## Security notes
- The service validates that the requested graph path is always under the passed `directory` parameter and rejects directory traversal attempts.
- The status panel sandbox allows only scripts/same-origin execution for graph iframes and injects its content safely via `doc.write()`.
