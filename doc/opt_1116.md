# Panel UI 優化計畫 `opt_1116`

日期：2026-11-16
審計分支：`opt`（自 `panel` 建立）

## 【目標】

提升 OpenChamber Panel UI 的可用性與正確性，解決圖例與縮放控制行為異常、載入狀態不明晰等問題，並補齊無障礙與可維護性細節。目標實作後 review 分數 **≥90**。

---

## 【審計範圍】

- 檔案：`panel/main.ts`（HTML/CSS/TypeScript 嵌入式 Web Panel）
- 頁面：Graph / Report / Analysis 三標籤面板，透過 vis-network 呈現互動圖。

## 【審計結果摘要】

總共找出 **3 Critical / High、4 Medium、5 Low/Light** 問題：

| 嚴重度 | ID      | 短描述                                       |
|---------|---------|----------------------------------------------|
| Critical | C1     | `legendDiv` 未宣告導致 TypeScript 隱式 any |
| Critical | C2     | Zoom 輸入框狀態與實際縮放脫鉤                |
| Critical | C3     | 圖例 label 點擊雙重互補導致不可用            |
| Medium   | M1     | Markdown 標題層級錯誤（#→h2而非h1）         |
| Medium   | M2     | 圖形載入與穩定階段無 Loading 視覺回饋       |
| Medium   | M3     | `.content.active` height:auto 造成 flex 區域不佔滿剩餘空間        |
| Medium   | M4     | 社群顏色只預設前7組，超過時變為灰色不明顯    |
| Medium   | M5     | 圖例篩選與邊 visibility 計算易因 `indexOf` 錯誤 |
| Low      | L1     | 無鍵盤縮放快捷鍵（+/-/0）                    |
| Low      | L2     | 報告 parser 未支援連結與表格等 Markdown       |
| Low      | L3     | Graph 錯誤畫面無 Retry 按鈕                  |
| Low      | L4     | Tab UI 缺少 ARIA role/selected                |
| Low      | L5     | graph-controls button 的對比度 / hover 狀態不夠明確|

## 【實作順序與 Plan】

1. **Commit 1 (`C1`) – TypeScript 強型別補齊**  
   - `drawGraph` 中引入 `let legendDiv: HTMLElement | null = null;`
2. **Commit 2 (`C3 + C2`) – 圖例互動修正與 Zoom state sync**  
   - 移除 `labelEl.addEventListener('click'...)`，只保留 `input.change`
   - `applyFit(...)` 後以 `network.getScale()` 同步更新 `inputZoom.value`
3. **Commit 3 (`M1`) – 標題層級與視覺調整**  
   - Markdown heading map：`#→h1`, `##→h2`, `###→h3`，並修正對應 CSS 大小
4. **Commit 4 (`M2`) – loading indicator + `requestAnimationFrame` 顯示**  
   - 在 `drawGraph` 開始時顯示 `div.graph-loading`，完成後移除
5. **Commit 5 (`M3`) – flex layout 高度強制佔滿**  
   - `.content.active { display:flex; flex-direction:column; align-self:stretch; }` 移除 `height:auto`
6. **Commit 6 (`M4`) – 動態社群顏色循環**  
   - 新增 `getCommunityColor(cid: number): string`，使用 `hsl((cid * 470 % 360),65%,55%)`
7. **Commit 7 (`M5`) – 邊 visibility 正確計算**  
   - 使用 vis-network `hidden` node id filter + edge from/to hidden，而非重複找 index；或直接在 update 傳 `nodes`+`edges`。
8. **Commit 8 (`L1`) – 鍵盤快捷鍵支援**  
   - 圖形容器 `keydown` 處理：`+`/`-`/`0`（或 ctrl/modifier）
9. **Commit 9 (`L2`) – report parser 增強**  
   - 支援 `|` table，`<a>` 連結；保留現有簡單渲染邏輯。
10. **Commit 10 (`L3`) – graph error `retry`**  
    - 錯誤區域附加 Retry button；呼叫 `host.serviceRequest(...)`。
11. **Commit 11 (`L4`) – Tab ARIA role**  
    - tabs `role=tablist`, buttons `role="tab"`, `aria-selected`
12. **Commit 12 (`L5`) – controls contrast / focus**  
    - hover color 提高對比度，增加 `:focus-visible` ring。
